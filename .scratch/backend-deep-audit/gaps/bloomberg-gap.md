## 1. Scope, product context, and backend inventory

### Product context

FinEngine is a FastAPI portfolio-risk and equity-research application with portfolio, market-data, analytics, streaming, and equity-research routers (`backend/main.py:1-4`, `backend/main.py:119-148`). The data plane is India-first but accepts plain US/global symbols: Indian defaults and exchange suffixes are explicit, while non-Indian bare symbols pass through unchanged (`backend/app/services/data_service.py:28-67`). Historical data follows a user-selected bfinance/yfinance cascade, with Alpha Vantage last (`backend/app/services/data_service.py:377-443`, `backend/app/services/source_preference_service.py:24-31`, `backend/app/services/source_preference_service.py:81-85`).

The persisted model inventory contains a single current-position book, market timeseries/cache/fetch logs, and selected NSE microstructure/ownership tables; it contains no user/account, transaction, watchlist, saved-screen, or alert model (`backend/app/models/database.py:11-227`). That single-workspace shape is adequate for a personal portfolio, but saved artifacts and auditable performance require an explicit ownership model before multi-user use.

## 5. Do not do

1. **Do not add more risk-model variants yet.** EWMA/GARCH/EGARCH, tail risk, scenarios, liquidity, concentration, optimization, and regime analytics already exist (`backend/app/api/analytics.py:452-1180`, `backend/app/api/analytics.py:1556-1905`, `backend/app/api/analytics.py:2200-2247`). Another forecast variant does not fix the ledger, benchmark, or quality gaps.
2. **Do not automate NSE website collection.** NSE terms prohibit systematic or automated collection (`https://www.nseindia.com/static/nse-terms-of-use`, verified S4/S5). Use manual personal import for the basic build or buy licensed data.
3. **Do not add more hard-coded screen strategies before persistence.** Five strategies and a basic custom filter already exist (`backend/app/services/screener_service.py:73-99`, `backend/app/services/screener_service.py:276-352`). Saved definitions, watchlists, and alerts create more value than a sixth fixed idea list.
4. **Do not build a generic AI stock-picker surface.** The backend already emits company dossiers and analyst prompts (`backend/app/services/ai_dossier_service.py:26-110`); without auditable inputs and a decision ledger, another recommendation generator would add non-decision-moving output.
5. **Do not purchase terminal-grade data before proving the basic workflow.** Professional consensus breadth, licensed news, and holder-level ownership histories are paid-only upgrades. First ship B03, B08–B12, then buy only where measured gaps remain.

### Limitations and verification boundaries

- This was a backend-only product audit; frontend behavior and visual usability were not independently graded.
- Current-state conclusions are tied to exact Python lines. Runtime database population was not used as evidence because it cannot satisfy the required `file.py:line` citation contract.
- The benchmark is currently NIFTY 50-only (`backend/app/services/benchmark_service.py:19-23`), and performance history applies today’s quantity backward (`backend/app/api/analytics.py:1194-1259`). B01/B02 are therefore prerequisites for trustworthy performance claims.
- yfinance is an unofficial client and its README limits Yahoo data to personal use [S1]. FinEngine’s actual deployment rights were **not verified**.
- bfinance’s package license is MIT, but its upstream exchange-data rights and commercial-use suitability are **not verified** [S2]. This blocks any claim of unrestricted redistribution.
- NSE prohibits automated collection on its site [S4][S5]. Basic India ownership and flow ingestion must be manual or licensed.
- SEC endpoints, no-key access, 10 requests/second, and nightly bulk updates were verified by official search results; direct fetches returned 403. A declared User-Agent and a live integration probe remain required [S7].
- GDELT’s free/open status and article/tone API were verified, but exact content license and numeric rate limit are **not verified** [S9]. Keep the basic feed transparent and reversible.
- Kenneth French is US-only; exact content license and numeric rate limit are **not verified** [S10]. It may validate US factor exposures but must not be used as an Indian benchmark.
- World Bank macro history is broad but low-frequency and series-dependent [S8]. It is suitable for context cards, not a fast trading signal.
- yfinance field-by-field IN/US completeness, provider update schedules, and analyst-estimate coverage are **not verified** [S1]. Preserve raw snapshots, source dates, and nulls rather than implying completeness.
- No user/tenant model exists in the current persisted inventory (`backend/app/models/database.py:11-227`). Saved screens, alerts, and collaborative reports need a product decision on single-user versus multi-user ownership before implementation.

## Final product recommendation

Make **B01–B05** the trust spine: transaction ledger, benchmark-relative performance, data quality, complete risk decomposition, and execution-realistic backtests. Then ship **B06–B12** as the first decision layer: factors, comps, events, estimate revisions, news, ownership, and corporate actions. Defer paid data and network breadth until usage demonstrates that the free builds are insufficient.
