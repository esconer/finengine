## Bugs

### P0 (security / data loss)

- [P0] `backend/main.py:175` / `backend/app/api/websocket.py:2260` — the entire mutating API (DELETE/PUT positions, POST rebalance, POST /data/cache/clear, POST /ws/broadcast) has **no authentication**, the default/documented bind is all-interfaces, and the WebSocket's `token` parameter is accepted but never read — a LAN client can wipe or rewrite the portfolio and inject messages into live dashboards. — `host="0.0.0.0",` (main.py:175; also `app.add_middleware` block adds no auth, and AGENTS/docs runbook uses `--host 0.0.0.0`); `async def websocket_endpoint(websocket: WebSocket, client_id: str, token: str = Query(None)):` (websocket.py:260) — `token` is never referenced anywhere in the function body; `@router.post("/broadcast")` + `await manager.broadcast(message, topic)` (websocket.py:326-338) is callable by anyone.
